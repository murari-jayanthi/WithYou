# 🌿 WithYou

An AI-powered mental wellness platform that helps users access emotional support, book appointments with doctors, and manage their mental well-being through a secure and user-friendly web application.

## 📌 Features

- 👤 User Registration & Login
- 🔐 Secure Authentication
- 🤖 AI-powered Mental Wellness Support
- 👨‍⚕️ Doctor Appointment Booking
- 📅 Appointment Management
- 🩺 Doctor Dashboard
- 👨‍💼 Admin Dashboard
- 📱 Responsive User Interface

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/murari-jayanthi/WithYou.git
```

### Navigate to the project

```bash
cd WithYou
```

### Install backend dependencies

```bash
npm install
```

### Install frontend dependencies

```bash
cd client
npm install
```

### Run the application

```bash
cd ..
npm run dev
```

The application will be available at:

- Frontend: http://localhost:3000
- Backend: http://localhost:8080
